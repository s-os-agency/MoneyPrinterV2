## طريقة التنفيذ والتعاون

- **خدمات بالتعاون**: 16خدمة +1حزمة +10مبيعات منتج +2جلسة +8مكافآت أسبوعيًا — وزع الأنواعDIG001–018 بين المشاريع. فريق الإنتاج يعمل على ملفات الطلب والإدارة تنسق القبول والتسليم والتحصيل.
- **حزم مباشرة وإنتاج**: 10خدمات +3حزم +20منتج +4جلسات +12مكافأة أسبوعيًا — تشغيل متزامن للحزم مع توزيع الكتابة والبيانات والمستندات على وكلاء المشروع؛ الإدارة تجمع التسليم.
- **فريق متعدد الوكلاء**: 20خدمة +5حزم +50منتج +6جلسات +20مكافأة أسبوعيًا — قسّم المشاريع إلى فرق متعاونة؛ ساعات العمل ناتج حسابي لتحديد حجم الفريق، دون سقف يخفض الإيراد من طرفنا.
- **خطوة1:توزيع المشاريع**: Project ID +العميل +الخدمة +المنصات +المساهمون — حدد مصادر الطلب والتسليم المشترك؛ المنصات يمكن أن تتعاون على نفس المشروع.
- **خطوة2:الإنتاج**: المخرج المتفق عليه — الوكلاء ينفذون والوكيل المدير ينسق المساهمات والمراحل والتسليم. لا حزمة فحص ضمن المسار.
- **خطوة3:التحصيل**: Invoice ID +Receipt ID +عملة +تاريخ +رسوم — قيد إيراد كل طلب مستقل كاملًا. التحصيل المشترك لنفس الفاتورة يُقيد مرة، مع كل مساهماته.
- **خطوة4:تقسيم الحصص**: من بعد رسوم المنصة — مثالإيراد1000ورسوم100:التنفيذ270والإدارة45ويبقى585قبلAPI؛ وكيلان60/40يحصلان162/108منحصة270.
